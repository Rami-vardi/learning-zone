# Learning Zone

Standalone desktop Learning Zone app for training program design, exercises, case studies and the PDF Library.

Student work, teaching cases and PDFs use the connected Supabase backend. No private student data or server secrets are stored in this repository.

## Hosting

In Settings → Pages, select Deploy from a branch, main, and / (root), then Save. The entry point is index.html.

## Updates

Update index.html on main to publish the next app version. Keep backend source, private case profiles, test files and credentials out of this public repository.
