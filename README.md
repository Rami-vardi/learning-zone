# Learning Zone

Standalone desktop Learning Zone app for training program design, exercises, anatomy, case studies, whiteboards and the PDF Library.

Student work, teaching cases, PDFs and whiteboard sharing use the connected Supabase backend. No private student data or server secrets are stored in this repository.

## Hosting

In Settings → Pages, select Deploy from a branch, main, and / (root), then Save. The entry point is index.html.

## Updates

Publish index.html together with the matching version of its local JavaScript, CSS and anatomy assets. Anatomy assets load when the zone opens. Keep backend source, private case profiles, test files and credentials out of this public repository.

Anatomy model and Three.js license notices are included under anatomy/.
